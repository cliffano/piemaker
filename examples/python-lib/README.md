# PiemakerLibExample

PiemakerLibExample is a A sample Python library project generated by Piemaker .

## Installation

```shell
pip3 install piemakerlibexample
```

## Usage

Create a configuration file, e.g. `piemakerlibexample.yaml`:

```yaml
---
text: Hello World
```

Create piemakerlibexample object and run it:

```python
from piemakerlibexample import Display

display = Display(conf_files=['piemakerlibexample.yaml'])
text = display.format(reverse=False, transformation='lower')
print(text)
```

## Configuration

These are the configuration properties that you can use with `piemakerlibexample` CLI.
Some example configuration files are available on [examples](examples) folder.

| Property | Type | Description | Example |
|----------|------|-------------|---------|
| `text` | String | The message text | Hello World |
