# PiemakerExample

PiemakerExample is a A sample Python CLI project generated by Piemaker .

## Installation

```shell
pip3 install piemakerexample
```

## Usage

Create a configuration file, e.g. `piemakerexample.yaml`:

```yaml
---
text: Hello World
```

Run piemakerexample with specified config file:

```shell
piemakerexample --conf-file piemakerexample.yaml
```

Run piemakerexample with specified config file and custom flags:

```shell
piemakerexample --conf-file piemakerexample.yaml --reverse --transformation upper
```

Show help guide:

```shell
piemakerexample --help
```

## Configuration

These are the configuration properties that you can use with `piemakerexample` CLI.
Some example configuration files are available on [examples](examples) folder.

| Property | Type | Description | Example |
|----------|------|-------------|---------|
| `text` | String | The message text | Hello World |
